# POS Git Demo

Dieses Repository wurde für die Git-Hausübung erstellt.

## Durchgeführte Git-Befehle

- `git init` – lokales Git-Repository erstellt
- `git add` – Datei zur Staging Area hinzugefügt
- `git commit` – Änderungen lokal versioniert
- `git push` – lokale Commits auf GitHub hochgeladen
- `git clone` – Repository lokal geklont
- `git pull` – Änderungen von GitHub lokal übernommen
- `git log --oneline` – Commit-Historie angezeigt
- `git diff` – Änderungen zwischen Versionen angezeigt
